# Acknowledgments

Private Directory Server is a free, open-source project directed and published by Jaye.

The program is being developed through collaborative work between a human creator and multiple AI development tools. Human input establishes the product goals, acceptable risk, intended behavior, and final publishing decisions. AI tools assist with implementation, review, documentation, testing strategy, and investigation.

The project describes that process as vibe coding without using the term as an excuse for unverifiable software. Contributions are accepted based on understandable behavior, focused scope, passing tests, and real runtime evidence—not on whether the first draft came from a person or an AI system.

Thanks also go to future contributors who report problems clearly, improve portability, strengthen the security boundary, or make the tool easier for non-developers to use.
